# Roadmap

## Phase 1 — MVP (current)

- [x] Sample road network (Chennai central / Anna Salai corridor)
- [x] Map display with selectable road segments
- [x] Close/modify scenario configuration
- [x] Graph-based traffic redistribution simulation
- [x] Before/after impact dashboard
- [x] AI Copilot (scenario parsing + result explanation)
- [x] End-to-end demo flow

## Phase 2 — Polish

- Real OSM network fetch via OSMnx for Chennai
- Rush-hour demand profiles (morning / evening)
- Scenario templates and history
- Export impact summary (PDF/JSON)
- Improved map styling and legend

## Phase 3 — Scale

- Multi-city support
- User accounts and saved scenarios
- WebSocket live simulation progress
- PostgreSQL/PostGIS for network storage

## Future (out of MVP scope)

- SUMO microscopic simulation
- Redis/Celery job queue
- GNN/LSTM traffic forecasting
- Computer vision incident detection
- Voice control
- Automated policy-report generation
